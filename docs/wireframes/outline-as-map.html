The rules the map obeys

  • One grammar, four zooms. Exam spine → topic segments → set cards → frame strip → (later) the student landing map. The run rail you shipped is this grammar at zoom 4; this is zooms 1–3.
  • Size = weight, color = readiness. Segment height is CEQ count; green/amber is the same pure check behind “Ready to film?”. The header “72% ready” is the whole exam self-grading — for partners, it's their scoreboard.
  • Nothing is deleted. Every current outline capability keeps a home: rename/park/delete → right-click or ··· menus; CSV import/export + Snapshot Flow → topic-header ··· ; drag-reorder → drag cards/segments; level-3 CEQ rows → the strip already does this better.
  • The spine never leaves. States 2–3 keep the 44px miniature — you're never “inside a folder”, you're at a place on the map. (Hover a spine segment = tooltip with topic name + readiness.)
  • Partner-shaped by accident. Give a tutor one topic: their map is just… smaller. The exam switcher (▾) is where Exam 2 / Final / other courses live — and later, other tutors' exams you're reviewing.
