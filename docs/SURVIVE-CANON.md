Any new AI session (or teammate) working on Survive starts here. These four docs are the
franchise recipe + state of the world; they are authoritative over ad-hoc chat context.

1. **[SURVIVE_MASTER_CONTEXT_V2.md](SURVIVE_MASTER_CONTEXT_V2.md)** — read FIRST. State of the
   build + locked vocabulary (Blast Off / Jam / Vibe / Nerd Out), production workflow, the
   Transcript Law, near-term execution order, guardrails.
2. **[SURVIVE_METHOD_v1.md](SURVIVE_METHOD_v1.md)** — Lee's voice & teaching philosophy: the
